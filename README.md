# KT J1 MARKET - 동탄역점

GitHub Pages용 정적 웹사이트입니다.

## 파일
- `index.html` : 전체 페이지
- `styles.css` : 반응형 디자인
- `script.js` : 메인배너, 상품필터, 상담 폼 동작

## GitHub Pages 적용
현재 `dongtan-kt` 저장소의 기존 파일을 백업한 뒤 이 세 파일로 교체하고 commit/push 하면 됩니다.
GitHub Pages가 `main / root`를 바라보고 있다면 별도 설정 없이 반영됩니다.

## 꼭 수정할 곳
### 1. 사업자 정보
`index.html` 하단에서 아래 문구를 검색해 실제 번호로 교체하세요.
- `등록번호 입력`
- `신고번호 입력`

### 2. 상담 자동접수
현재는 개인정보가 서버로 전송되지 않도록 기본값이 **상담내용 생성/복사** 방식입니다.
자동접수를 사용하려면 `script.js` 첫 줄의 `FORM_ENDPOINT`에 사용하는 폼/API 주소를 넣으세요.

```js
const FORM_ENDPOINT = 'https://...';
```

### 3. 프로모션 문구
지원금/사은품은 실제 매장 운영 조건에 맞춰 수정하세요. 현재 문구에는 조건 변동 안내를 함께 넣었습니다.

## 참고
- 모바일 하단에는 `전화상담 / 맞춤견적 / 휴대폰` 고정 메뉴가 표시됩니다.
- 상품 카드는 `전체 / 삼성 / 애플` 필터가 동작합니다.
- 메인 배너는 자동 슬라이드됩니다.
